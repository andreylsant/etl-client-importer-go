# ETL Implementar um ETL (Extração, Transformação e Carga) em Go (Golang) envolve estruturar o código em três fases principais: Extração (ler de uma origem como CSV ou banco), Transformação (limpar ou alterar os dados) e Carga (salvar no destino)

# Requisito --> Ler um arquivo CSV com cliente, tratar os dados e gravar no postgreSQL
